## What ADP is

Some things are understood better as a picture than as prose, and better as a picture made for that one task than as a general-purpose one. ADP gives each such task its own tool, and keeps what the tool shows in plain files beside the work it describes, so a view can be reviewed, branched and merged like any other text.

## Where ADP runs

Every tool type is specified once, in a specification language, and runs in each of the four IDE hosts. Notion is a planned host: no tool is available in it yet.

## Source
