The documentation part of this site explains how ADP designers are defined and what each one does. It grows section by section; a section marked "Coming" says what it will hold and is filled in by a later specification.

export const blurbs = {
	dedl: 'The Diagram Editor Definition Language specification, section by section, with its schema and examples.',
	designers: 'The catalogue of designers, with the task each one is for and the hosts it runs in.',
};

The words used throughout are defined on the [Terminology](/adp/docs/terminology/) page.
