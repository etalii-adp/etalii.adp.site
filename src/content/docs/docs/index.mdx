The documentation part of this site explains how ADP tools are specified and defined, and what each one does. It grows section by section; a section marked "Coming" says what it will hold and is filled in by a later specification.

export const blurbs = {
	specification: 'The languages in which tool types are specified and tools are stored, one pair per kind.',
	disl: 'The Diagram Specification Language specification, section by section, with its schema and examples.',
	did: 'The Diagram Definition Language specification, section by section, with its schema and examples.',
	tools: 'The catalogue of tools, with the task each one is for and the hosts it runs in.',
	research: 'Analyses of how people think and work, and what that asks of specialised tools.',
};

The words used throughout are defined on the [Terminology](/adp/docs/terminology/) page.
